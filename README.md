# SQL для коммерческой и финансовой аналитики (T-SQL)

## 📋 Описание репозитория
Мой практический проект по автоматизации регулярных экономических расчетов. Я локально развернула демонстрационную базу данных торговой сети и спроектировала серию скриптов на базе **обобщенных табличных выражений (CTE)** и **оконных функций**. 

Цель проекта — создать библиотеку готовых SQL-шаблонов, которые позволяют быстро извлекать данные и рассчитывать ключевые бизнес-метрики без ручной пересборки в Excel.

## 🧠 Реализованные экономические кейсы и бизнес-логика:

1. **Динамика продаж Month-over-Month (MoM Growth %)**
   - **Инструменты**: Двухуровневые CTE, функция смещения `LAG`, безопасное деление через `NULLIF`.
   - **Что считает**: Рассчитывает ежемесячную выручку и чистый темп прироста или падения продаж в процентах к прошлому месяцу. Защищает расчет от ошибок деления на ноль.

2. **Расчёт накопительного итога (Running Total)**
   - **Инструменты**: Оконное агрегирование `SUM(...) OVER(ORDER BY ...)`.
   - **Что считает**: Скользящую выручку день ко дню. Позволяет коммерческому департаменту в реальном времени отслеживать динамику выполнения планов продаж.

3. **Анализ ценообразования и отклонений от рынка**
   - **Инструменты**: Аналитическое окно `AVG() OVER()` без разрушения структуры строк.
   - **Что считает**: Выводит список всех SKU и автоматически рассчитывает дельту их стоимости по отношению к средней рыночной цене для поиска переоцененных или недооцененных позиций.

4. **АВС-ранжирование и сегментация ассортимента для акций**
   - **Инструменты**: Функции ранжирования `ROW_NUMBER()` и `DENSE_RANK()` внутри секций `PARTITION BY`.
   - **Что считает**: Выделяет ТОП-3 и ТОП-5 самых дорогих и маржинальных товаров в разрезе каждой категории для фокусных маркетинговых активностей и оценки премиум-сегмента.

5. **Расчет KPI и оценка эффективности персонала (SFE)**
   - **Инструменты**: Группировки `COUNT` в связке с ранжированием `ROW_NUMBER()`.
   - **Что считает**: Автоматически ранжирует сотрудников по количеству оформленных заказов внутри каждого подразделения для расчета премий и оценки KPI.

## 💻 Стек технологий
Microsoft SQL Server (T-SQL), Window Functions, CTE.
