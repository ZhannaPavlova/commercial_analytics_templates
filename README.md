# SQL для коммерческой и финансовой аналитики (T-SQL)

## 📋 О проекте
Библиотека готовых SQL-шаблонов для автоматизации регулярных экономических и коммерческих расчетов с использованием демонстрационной базы данных торговой сети. Проект заменяет ручную работу в Excel воспроизводимыми запросами на базе **CTE** и **оконных функций** (Window Functions).

---

## 📂 Структура репозитория
```text
commercial_analytics_templates/
├── README.md       # Описание проекта, логика метрик и навигация
└── sql_cases/      # Папка с отдельными SQL-скриптами под каждый бизнес-кейс
```

---

## 🧠 Реализованные бизнес-кейсы и логика расчетов

* **1. Динамика продаж Month-over-Month (MoM Growth %)** (`sql_cases/01_mom_sales_growth.sql`*) — расчет выручки и темпа прироста/падения с помощью `LAG()` и `NULLIF()`.
* **2. Расчёт накопительного итога (Running Total)** (`sql_cases/02_running_totals.sql`*) — скользящая выручка день ко дню через `SUM(...) OVER()`.
* **3. Анализ ценообразования и отклонений от рынка** (`sql_cases/03_price_analysis.sql`*) — сравнение SKU со средней рыночной ценой через `AVG() OVER()`.
* **4. ABC-ранжирование и сегментация ассортимента** (`sql_cases/04_abc_segmentation.sql`*) — выделение топ-товаров внутри категорий с помощью `ROW_NUMBER()` и `DENSE_RANK()`.
* **5. Расчет KPI и оценка эффективности персонала (SFE)** (`sql_cases/05_staff_kpi_sfe.sql`*) — ранжирование сотрудников по заказам в подразделениях.

## 💻 Стек технологий и навыки
* **СУБД:** Microsoft SQL Server (T-SQL)
* **Продвинутый SQL:** CTE, Window Functions (`LAG`, `ROW_NUMBER`, `DENSE_RANK`, `SUM`, `AVG`), работа с `NULLIF`, `COALESCE`.
* **Доменная экспертиза:** Коммерческая аналитика, SFE, ценообразование, управление ассортиментом.
